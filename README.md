# Словолітера

Простий пошук українських слів за кількома окремими літерами. Порядок літер не має значення, повтори враховуються.

Словникова база сформована з відкритого морфологічного словника [ВЕСУМ](https://github.com/brown-uk/dict_uk).

Сайт автоматично публікується на GitHub Pages із каталогу `dist`.
